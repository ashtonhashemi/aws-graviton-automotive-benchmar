Measured AWS mode

P2Tester is measured end-to-end on the external Tester EC2 monotonic clock over real persistent TCP/IPv4 inside the VPC. Target ECU processing is a controlled test stimulus. Per-node processing is measured locally; cross-host wall clocks are recorded for observability but are not used to calculate the P2Tester result.
